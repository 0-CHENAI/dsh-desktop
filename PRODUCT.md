# Product

## Register

product

## Users

DSH Desktop serves people who want to run DeepSeek Harness as a dependable local desktop application instead of assembling a command-line environment themselves. They configure model providers, portable agent presets, workspaces, mobile access, and editable presentation generation while expecting their data and credentials to remain under their control.

## Product Purpose

DSH Desktop packages the local-first DeepSeek Harness runtime into an installable, cross-platform host. Success means users can reach a working agent session, understand and configure the capabilities available to them, recover safely from extension failures, and upgrade without losing profiles, workspaces, model settings, or conversations.

## Brand Personality

Practical, trustworthy, and calm. The product should explain consequential state plainly, keep advanced power accessible, and feel like a focused native tool rather than a promotional surface.

## Anti-references

- Interfaces that hide important capability or authentication state behind unexplained names, dots, or hover-only affordances.
- Marketing-style decoration that competes with configuration tasks.
- Security shortcuts that ask users to weaken their operating system or expose credentials.
- Novel controls where a familiar desktop or web affordance communicates the task more clearly.

## Design Principles

- Make capability and state visible before the user commits to an action.
- Keep local data ownership and explicit consent at every security boundary.
- Reuse one coherent workflow across providers and plugins instead of creating vendor-specific islands.
- Prefer recoverable actions and actionable diagnostics over silent failure.
- Preserve familiar interaction patterns so the tool disappears into the user's work.

## Accessibility & Inclusion

Interactive controls must remain keyboard operable, expose meaningful accessible names and live status, retain a visible focus treatment, and communicate state with text as well as color. Motion must respect reduced-motion preferences. Layouts and localized text must remain usable at narrow desktop widths and common display scales.
