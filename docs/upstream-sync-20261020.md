## 审查后的修复与优化

1. Word worker 清理环境变量时保留 Windows `TEMP/TMP`，避免 ACL runner 向系统目录写锁；密钥及其余环境仍被清理。
2. 通知 IPC 校验主窗口和主 frame；重载、销毁与重复 ID 不得把旧回调交给新实例。同文档会话导航继续保留通知。
3. 通知显示以原生确认事件为准；显式关闭后仍可接收一次关闭回调；原生失败通知到页面并释放状态。
4. Safe Mode 拒绝无效 YAML、替换模型实现及第三方插入，展开后再筛选 YAML 别名；仅保留模型参数，不复制普通 Profile 的核心服务禁用状态。
5. 更新时保持进度节点与焦点，切换语言时同步刷新全部文案；隐藏时不响应其他弹窗的 Esc；安装期间禁止关闭或跳过；错误保留至用户处理，回退只接受实际历史版本。
6. 修正 Mac 手动更新说明，不承诺安装另一个 ad-hoc 版本即可启用自动更新。
7. Windows batch 注入路径转义字面 `%`，避免安装目录中的字符被解释为环境变量。
8. Windows 目录链接回归使用无须管理员权限的 junction，继续验证实际目录/文件越界，保留 POSIX 文件软链接覆盖。
9. Office 模式、会话与已选案例变化时，在控件可交互前清理旧预览，防止延迟 effect 撤销新点击；预览结果绑定页码、案例版本和重试请求，避免旧双页内容配上奇数末页尺寸。新增 4 项实际 React 行为回归，均先复现失败再验证修复。
10. 原生 UI 检查等待初始会话完成绑定，避免在即将卸载的 sessionless hero 上点击。原生 CI 对 Mac 两种架构和 Windows 统一串行执行测试文件，保留原有断言与超时；补充 macOS 15 独立字体检查和失败渲染产物，继续观察曾出现的重算超时及空白渲染，不将资源竞争推断为已确认的产品根因。
11. macOS 15 独立回归确认空白预览同时报告缺少 `PingFang SC Semibold`；macOS 14 的同场景没有缺失字体。为苹方各字重名称增加显式中文回退组，不修改原始字体身份或已安装字体的优先级。回归产物仅补充字体族、样式和字重，不上传个人路径或完整字体缓存；真实 Mac 修复结果以最新 SHA 检查为准。
12. Windows 原生退出探针不再逐次启动 PowerShell 编译 C#，改用已锁定的 Koffi 在独立 Electron Node 进程发送限时消息；校验父进程、窗口归属及消息白名单。原有退出/重启断言保留，新增拒绝其他进程和未批准消息的原生场景；不触发真实关机、注销或广播。

原生打包及 PR 检查继续覆盖 Windows/macOS；包内 Office/PPT 生成与导入由 afterPack 验证。
