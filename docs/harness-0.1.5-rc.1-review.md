# Harness 0.1.5-rc.1 迁移审查

审查日期：2026-09-10。范围为当前工作树从 0.1.2-rc.1 到 0.1.5-rc.1 的依赖、补丁、启动入口、持久化、配置兼容与 PPT 适配。0.1.5-rc.1 是候选版。以下修复已应用到正式 patches，并经过干净安装回读。

## 发现与修复

| 严重程度 | 问题 | 原因 | 修改方式与证据 |
| --- | --- | --- | --- |
| 高 | 工作区列表和搜索栏样式失效 | JavaScript 中 CSS 模块映射残留旧版 WL7F9W 哈希，实际 CSS 已是 bhn1Oq | 恢复新版映射；回归检查每个映射都有实际样式；浏览器展开搜索后核验计算样式与截图 |
| 高 | RPC 注册作用域不正确；此前补救会强制非 Web 连接宿主依赖 Web 服务 | Cordis 服务代理上下文带有 provider shadow，直接捕获不能保留调用插件所有权 | 使用公开 getTraceable API 恢复调用上下文，HTTP 路由按需注入 WebServer；验证无 Web 启动、延迟挂载、卸载、同名 RPC/Fetch 重挂和完整 Desktop PPT 鉴权调用 |
| 中 | 从搜索结果进入会话后仍显示未读 | 新版搜索路径直接 open，绕过 Desktop 的 markSessionRead | 复用 openSession，同时保留清除搜索和定位会话行为；测试真实回调的状态变更顺序 |
| 低 | Persona 配置校验与类型声明不一致 | 兼容旧 text 后未同步类型约束，缺失文本只能在 apply 阶段报错 | schema 要求 prefix 或旧 text 至少一个有效字符串；同步类型声明，保留显式空 prefix 优先；全局 persona 兼容字段同步声明 |

另移除 Agent 预设中已无对应样式的遗留 badge 映射，避免继续携带无效升级差异。

## 业务合同检查

- 会话删除沿用新版 SessionHandle，检查活跃句柄、写入所有权和文件锁；删除全部日志代际，避免旧代际让会话再次出现。定向测试覆盖锁冲突、删除后读取和其他会话不受影响。锁冲突测试使用同进程独立 Context，尚未补充独立操作系统进程崩溃注入。
- Persona 旧字段只作为回退，新字段包含空字符串时仍优先，不重写用户配置。
- PPT 事件序号、开关、重启恢复、旧快照清理和真实 RPC 鉴权纳入测试。
- 保留安全模式、第三方插件代际更新兼容及 main 自动发布配置。
- 官方 tarball 来源与完整性由 provenance 和 lock 记录；所有补丁从官方包差异生成，避免仅修改 node_modules。

## 发布前 CI 补充

main PR 的 Windows/macOS 检查首次在安全模式故障注入的 30 秒测试启动预算处超时；本机单独重跑该用例通过，约 18 秒。该测试预算提高到 90 秒，以覆盖 CI 冷模块解析和故障注入开销；保留必须捕获指定缺失依赖错误及恢复后真实 HTTP 鉴权的断言，超时仍判失败。产品运行时启动预算保持不变，最终平台结果以 PR 检查为准。
